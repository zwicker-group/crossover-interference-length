# Development information

## Pushing updates to public website

This repository contains the code for a webpage that allows users to calculate interference lengths and other statistics, which we publish on our github.io website at https://github.com/zwicker-group/zwicker-group.github.io.
To reflect any updates to the code in the present repository, one simply needs to update the subpackage `crossover-interference-length` in the [`zwicker-group.github.io` repository](https://github.com/zwicker-group/zwicker-group.github.io) and the webpage will be re-rendered by Github.
